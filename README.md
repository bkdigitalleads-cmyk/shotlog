# shotlog

Shot Log for iPhone, for the App Store as "Peptide Tracker: GLP-1 Shots" (subtitle "Shot, Protein & Weight Log"). Log a shot in a few seconds with the dose and the site, always know when the next one is due and where it goes in your own rotation, see weight and how you feel against your shots, and bring your prescriber a clean report. Works offline, and nothing leaves the phone. A personal log, not medical advice.

Expo SDK 57, React Native, TypeScript, expo-sqlite, RevenueCat, expo-print. See CLAUDE.md for how shipping works and NOTES.md for the change log.

```
npm install
npx tsc --noEmit
npm test
npx expo start --ios
```
